# Veilocity Android v2.80.36 — Offline Office and Outlook previews

Adds read-only `.docx` text preview and `.msg` Outlook email preview, including available metadata, message body and attachment names. Recognizes legacy `.doc` files but does not yet decode their binary text. Original files are never modified. Existing WAV/audio/video, PDF, HTML, XLSX and image functionality is unchanged. Android versionCode: 316.

Tested the Java parser independently with the supplied DOCX and MSG samples; the complete Android application was not built or device-tested.
