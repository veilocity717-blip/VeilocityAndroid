# Veilocity 2.3.2 PDF viewer improvements

- Repeated zoom in/out steps: 0.5x–8x relative to fit-to-width, in 1.25x increments.
- Rendering is bounded to approximately 6 million pixels per page for memory safety; on large pages, apparent zoom may stop increasing at the cap.
- Multiple bookmarks per PDF, shown as a numbered page list. Tap a bookmark to navigate, or use Remove bookmarks to delete an individual entry.
- Existing single-page bookmarks are migrated when changed.
- Tap the current page number to jump directly to another page.
- Retains the previous Library/Court button spacing and all existing functionality.
- Not compiled or device-tested in this environment.
