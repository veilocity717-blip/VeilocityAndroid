# Veilocity v2.4.2 — HTML find, nested library, launcher badge

Based on the donation-free v2.3.9 project. No donation or support page is added.

- Tap the magnifying glass (⌕) in the main navigation toolbar while viewing HTML to search the current WebView page. Enter a term and use Previous/Next to navigate matches. Closing the dialog clears matches. When viewing a PDF, the same main-toolbar button opens the existing PDF search; the existing PDF search button remains in its PDF toolbar.
- Open Library to browse directories under 1_Library. Folder entries open generated virtual pages; the Parent folder link navigates upward. PDF links in nested folders open the existing native PDF viewer. No extra index.html files are needed in subfolders.
- Android launcher icons use the supplied circular transparent Veilocity badge. Adaptive icons retain transparent padded foreground for launcher masking.
- Original archive and Court of Illusions links, video behavior, bookmarks, zoom, and PDF page navigation are unchanged.

Build with Android Studio. Expected output: Veilocity-v2.4.2-release.apk. Not compiled or device-tested here.
