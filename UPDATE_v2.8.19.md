# Veilocity Android v2.8.19 — Floating HTML Find

Based directly on the user-supplied v2.8.18 Google Drive Download Link project (not the experimental translation build).

- Replaces the HTML Find in page modal dialog with a compact, draggable non-modal panel.
- Drag using the panel heading; search, Previous, Next and Close remain functional.
- WebView remains scrollable while search panel is visible.
- No changes to PDF search, attachment viewers, offline Court links, downloads or translation.
- Android build/device test still required.
