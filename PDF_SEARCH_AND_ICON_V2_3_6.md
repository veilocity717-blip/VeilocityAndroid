# Veilocity v2.3.6

- Updated launcher icon: enlarged circular glossy artwork.
- PDF viewer: Search PDF button with search results and page navigation.
- PDF text search uses Android 15+ PdfRenderer text extraction (API 35); on older devices it displays a compatibility message. Image-only PDFs are not searchable without OCR.
- Search checks extractable text on each page, not text highlights; tap a result to open the matching page.
- Preserves v2.3.5 shared Court redirect, Library, zoom, bookmarks, and media controls.
- Release lint workaround retained.
- This source project has not been compiled or tested on a device.
