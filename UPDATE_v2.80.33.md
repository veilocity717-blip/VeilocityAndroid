# Veilocity Android v2.80.33 — Offline XLSX Viewer

- Added a lightweight read-only XLSX viewer for Library files and nested Library folders.
- Uses Android's built-in ZIP/XML parsing, with no network access or new dependencies.
- Added scrollable tables, worksheet tabs, and stored cell values.
- Preserved PDF search overlays, floating panels, archive navigation, and existing viewer features.
- Bumped Android versionName to 2.80.33 and versionCode to 313.

Limitations: formula results are not recalculated; full Excel formatting, charts and date formatting are not supported. Large sheets are preview-limited. Not compiled or tested on a physical Android device.
