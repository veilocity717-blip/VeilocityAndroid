# VeilocityAndroid

**Veilocity — multilingual archive viewer for Android**  
**Version:** 2.80.40

VeilocityAndroid is an Android Studio project for browsing a locally stored multilingual archive of HTML pages, documents, images, and videos. The app displays its bundled homepage immediately, even without a selected archive folder. Select an Arkhive folder on your device to browse its HTML pages, documents, images, and videos offline using the WebView and native document controls.

> The app bundles starter homepage artwork and a download catalogue. Full country, Court, and Library archive content is supplied separately.

## Offline Word and Outlook previews (v2.80.40)

- `.docx`: offline, read-only extraction of paragraph text from Word XML (not pixel-perfect layout; tables are presented as text).
- `.msg`: offline, read-only Microsoft Outlook OLE email preview, including available headers, plain-text body, and attachment filenames. Attachments are not yet extracted/opened.
- `.doc`: recognized as a legacy Word OLE file; full text extraction is not yet supported and is explicitly reported rather than guessing document content.
- Existing `.wav`, other audio/video, PDF, HTML, XLSX, image, and archive handling is unchanged.
- Preview pages include basic text magnification. No network connection or external Office application is required.

## Offline XLSX spreadsheet preview (v2.80.35)

Place `.xlsx` files anywhere within the selected `Arkhive/1_Library/` folder, including subfolders. Open **Library** and tap a spreadsheet to display it inside Veilocity without an internet connection or external Excel application.

The lightweight, read-only viewer supports multiple worksheet tabs, horizontal/vertical scrolling, stored text and numeric cell values, and WebView text search. It does not recalculate formulas or reproduce Excel charts, merged-cell layouts, all formatting, or Excel date/number formatting. To avoid excessive memory usage, previews are limited to 12 worksheets, 1,000 rows per worksheet, 80 columns, 50,000 populated cells and 120,000 displayed cells; large workbooks may show a limit notice. XLSX is supported; legacy `.xls` and `.ods` are not yet supported. Original files are never modified.

### Simple setup and additional countries

The **VeilocityAndroid with English Bundle** is the easiest starting point: it already contains the **English** and **Court of Illusions** archives in the `Arkhive` folder. Copy the extracted `Arkhive` folder to the root of Android shared internal storage, commonly shown as `/sdcard/Arkhive/`. Open VeilocityAndroid, select the **Arkhive** folder using the Android folder picker, and grant access.

To expand your archive, download other countries from the volumes above and place their country folders alongside the existing English and Court folders **inside the same `Arkhive` root**. Preserve each folder's internal HTML and media paths, and use the app's Refresh control after adding content. You can also select an archive folder stored elsewhere on your device.

The archive files are usable offline after copying them to the device; opening MEGA download links requires an internet connection.


## Features

- **Offline archive browsing:** Select an archive root folder using Android's system folder picker. The app reads files through the Storage Access Framework.
- **Bundled homepage:** Displays the Veilocity landing page, artwork, and downloads without requiring a selected archive folder. Available country folders are discovered after folder selection; missing manifests can be generated in memory.
- **Contextual setup guidance:** When no Arkhive folder is selected, the Download Country Archives card shows the folder-picker guidance and button. The guidance disappears once a folder is selected; the toolbar picker remains available.
- **Court and Library empty states:** Missing Court and Library content is explained with consistent styled pages rather than a raw missing-file error.
- **Floating Find panels:** Compact, draggable search panels for HTML and searchable PDF documents; PDF search navigates matching pages.
- **HTML navigation:** Home, Back, Forward, Refresh, search within a page, and scroll-to-top/bottom controls.
- **Native PDF viewer:** Page navigation, zoom, text search, and per-document bookmarks.
- **Unified image viewer:** Opens local archive images with filename display, Zoom Out, Fit, Zoom In, zoom percentage, and touch zoom/pan controls.
- **Court and country images:** Supports the shared image viewer across archive pages while preserving clickable country flags and Back navigation with scroll-position restoration.
- **Video playback:** Click-to-load video placeholders reduce automatic media loading. Playback supports local byte-range requests and pauses other HTML5 videos on the same page.
- **Compact native controls:** Collapsible navigation toolbar and subtly rounded buttons.
- **Download Archives page:** A dedicated page provides MEGA links to the English Bundle, PC frontend, Court archive, and Volumes 1–13. External download links require internet access.
- **Local-first:** Archive files are served to the embedded WebView through an app-local HTTP server. The app does not require a hosted archive.

## Requirements

- Android Studio with an Android SDK supporting **compileSdk 35**
- Android device running **Android 8.0 (API 26)** or newer
- An archive folder copied to the device for offline Court, Library, and country content (not required to display the bundled homepage)

The Android project uses the application ID `org.veilocity.arkhive` and Android Studio project name `VeilocityAndroid`.

## Build from source

1. Clone or download this repository.
2. Open the **`VeilocityAndroid`** project folder in Android Studio (the folder containing `settings.gradle`).
3. Allow Gradle to sync and install any required SDK components.
4. Build a debug APK for testing, or use **Build → Generate Signed Bundle / APK** for a release APK.
5. For app updates, sign release builds using the same signing key as earlier releases.

Expected release APK name: **`Veilocity-v2.8.10-release.apk`** (subject to the project’s release build configuration).

> This repository does not include a prebuilt APK or signing credentials. The source archive was inspected, but a full Android build and device test have not been performed in this environment.

## Set up your offline archive

1. Download the **VeilocityAndroid with English Bundle** from MEGA and extract it. The included `Arkhive` folder already contains the English and Court archives.
2. Copy the complete `Arkhive` folder to the root of your Android internal storage, for example **`/sdcard/Arkhive/`**, preserving its subfolders and companion asset directories.
3. Optionally download additional country/language volumes from MEGA and add their archive folders alongside English and Court within `Arkhive` (do not nest an extra `Arkhive` folder).
4. Open Veilocity and tap the **folder selection** control (`▣`).
5. Select the **`Arkhive` root**, not an individual language or document folder, and grant access.
6. Browse the landing page; after adding or replacing archive content, use Refresh to update the listings.

Example structure:

```text
/sdcard/Arkhive/
├── index.html                    # Optional custom landing page
├── logo.png                      # Optional archive logo
├── archives.js                   # Optional pre-generated listing
├── court-of-illusions-trafficking/
│   ├── ENGLISH - Court.html
│   └── ENGLISH - Court.html_Files/
│       ├── screenshot-example-1234.png
│       └── document-example-5678.pdf
├── English v101/                 # Example language folder; version may vary
├── 1_Library/
└── [additional country/language folders]/
```

**Important:** HTML exports often refer to companion folders such as `ENGLISH - Court.html_Files`. Keep the HTML file and its matching asset folder together, with their original filenames. The display name of an attachment can differ from its actual stored filename.

### Is a PC manifest-generation script required?

**No.** The Android app can generate basic archive listings/manifests in memory. The included Python scripts are optional utilities for preparing a standalone desktop/browser archive or pre-generating metadata. They are not required for normal Android use.

## Privacy and connectivity

The app primarily reads the folder you explicitly select. It serves archive files to its own WebView through a localhost HTTP endpoint (`127.0.0.1`); that does **not** mean the archive is uploaded to a public web server. HTML pages may nevertheless contain external links or resources, so offline availability depends on the archive's contents.

## Known limitations

- Very large HTML pages and media-heavy archives may still strain Android WebView memory.
- Local video playback depends on formats/codecs supported by the device's Android WebView.
- Some Android document providers may not support efficient random access or report file sizes, which can affect video seeking.
- Verify image navigation and external download links on your target device before publishing a release APK.

## Image viewer return fix (v2.8.10)

When opening a local image from a section of an indexed HTML archive, the Android viewer now saves the active section and scroll offset. Returning with Back restores the section and position even if WebView reconstructs the document.

## v2.8.10 image overlay

Archive images now open in a full-screen overlay on top of the existing HTML page. Use the top-right X or Android Back to dismiss, preserving the original page and scroll position without a reload. Zoom, Fit and pinch gestures are available.


## v2.8.10 image overlay routing fix

Archive image links now use the same in-page overlay across HTML archives and generated Library pages. The WebView main-frame image fallback invokes the overlay instead of navigating to a separate image-viewer document. Close with X or Android Back; the underlying document stays loaded.

## v2.80.40 — Court-only in-app translation

The installed `ENGLISH - Court.html` page now has a floating language selector backed by Google ML Kit on-device translation. The first use of each language requires an internet connection to download its model; subsequent use can be offline. Translation affects visible Court HTML text only, never archive files or attachment URLs. Original English can be restored. Translation is machine-generated and should not be relied upon as an authoritative legal translation. Large pages may take time and complex dynamic content may not be covered. All other HTML pages and document/audio viewers are unchanged.
