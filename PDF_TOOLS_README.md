# Veilocity v2.3 — Offline PDF tools

- Tap the page number to jump directly to a page.
- Use the magnifying glass + to zoom in, minus to zoom out, and Fit to reset. Scroll horizontally and vertically while zoomed.
- Tap ☆ Save page to bookmark the current page for this PDF. Tap Go ★ to return to that saved page. Bookmarks persist in the app preferences. One saved page per PDF.
- Existing offline library, Court of Illusions navigation, and video behavior are preserved.

The PDF viewer uses Android PdfRenderer; it does not perform text search within a PDF.
Build and device test in Android Studio.
